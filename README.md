## ✨ الميزات الرئيسية

### 🌓 وضع ليلي/نهاري (Dark Mode)
- تبديل سلس بين الوضع الليلي والنهاري
- حفظ تفضيلاتك تلقائياً
- ألوان محسّنة لكل وضع
- راحة العين في الإضاءة المنخفضة

### 🌐 دعم متعدد اللغات
- **العربية** (RTL - من اليمين إلى اليسار)
- **الإنجليزية** (LTR - من اليسار إلى اليمين)
- تبديل فوري للغة مع تحديث كامل المحتوى
- حفظ اختيار اللغة

### 📱 تصميم متجاوب
- يعمل على جميع الأجهزة (Desktop, Tablet, Mobile)
- تجربة مستخدم سلسة وسريعة
- تحسينات بصرية احترافية

### ⌨️ اختصارات لوحة المفاتيح
- **Alt + T**: تبديل الوضع الليلي/النهاري
- **Alt + L**: تبديل اللغة

## 🔧 التخصيص

### تغيير البيانات الشخصية
عدّل القيم في ملف `index.html`:
```html
<h1 class="name">اسمك هنا</h1>
<p class="title">المسمى الوظيفي</p>
```

### إضافة لغات جديدة
أضف ترجمات جديدة في ملف `script.js`:
```javascript
const translations = {
    fr: {
        headerTitle: 'CV Professionnel',
        // ... إضافة الترجمات الفرنسية
    }
};
```

### تغيير الألوان
عدّل متغيرات CSS في `styles.css`:
```css
:root {
    --primary-color: #1e3a8a;
    --secondary-color: #3b82f6;
    /* ... */
}
```
